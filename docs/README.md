## Getting Started

### New to Harbor?
1. **[Download Harbor](../README.md)** - Get the latest version
2. **[Installation Guide](./GETTING_STARTED.md)** - Set up Harbor
3. **[Features Guide](./FEATURES.md)** - Learn what you can do
4. **[FAQ](./FAQ.md)** - Quick answers

### Want to Contribute?
1. **[Read Code of Conduct](../CODE_OF_CONDUCT.md)** - Community guidelines
2. **[Contributing Guide](./contribute.md)** - How to help
3. **[Git Workflow](./GIT_WORKFLOW.md)** - Development process
4. **[Architecture](./ARCHITECTURE.md)** - Project structure

### Setting Up Development
```bash
# Clone repository
git clone https://github.com/Ivantech123/Harbor.git
cd Harbor

# Install dependencies
npm install

# Set up development environment
npm run init

# Start development version
npm start
```

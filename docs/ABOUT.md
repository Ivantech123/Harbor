> [Русская версия](./ABOUT_RU.md)

## What is Harbor?

**Harbor Browser** is an independent, open-source web browser built on Firefox's proven foundation. We're creating a modern browsing experience with innovative features and extensive customization capabilities.

Harbor represents a fresh approach to web browsing—combining Firefox's security and reliability with a thoughtfully designed user interface focused on productivity and personalization.

## Our Mission

We believe that web browsers should be:

- **Independent** - Not controlled by corporations or other browser projects
- **Open** - Source code transparency and community-driven development
- **Secure** - Built on proven security foundations with regular updates
- **Customizable** - Users should control how their browser looks and behaves
- **Fast** - Optimized performance for modern web applications
- **Respectful** - Honoring user privacy and choice

## Why Harbor Exists

The web browser landscape has become dominated by a few large players. Harbor exists to provide an alternative that prioritizes:

1. **User Independence** - Control over your browsing experience
2. **Open Development** - Community participation in decisions
3. **Privacy Focus** - Data stays on your device
4. **Innovation** - New features without corporate constraints
5. **Freedom** - Freedom to fork, modify, and redistribute

## Key Features

### Spaces
Organize your browsing into isolated workspaces. Perfect for:
- Managing multiple projects
- Work/Personal separation
- Staying organized across contexts
- Quick context switching

Browse two pages side-by-side for:

- Watching tutorials while coding

- Organize tabs into groups
- Pin important tabs

### Live Folders

- Monitor GitHub repositories
- Subscribe to RSS feeds
- Smart bookmark collections
- Custom live content sources

### CSS Customization
- Powerful mods system for UI customization
- CSS-based theming
- No limits on what you can change
- Share mods with community

## Frequently Asked Questions

**Q: Why not contribute to Firefox instead?**  
A: Firefox is amazing, and we do contribute upstream. But we believe there's value in creating a distinct, independent alternative that can innovate on the UI and user experience layer.

**Q: Is Harbor just a Firefox skin?**  
A: No. While we use Firefox's engine, we've built significant custom components including our Spaces system, advanced tab management, Live Folders, and mods system.

**Q: How is Harbor funded?**  
A: Harbor is volunteer-driven with no commercial backing. We accept community support through GitHub Sponsors (coming soon).

**Q: Will Harbor remain independent?**  
A: Yes. We're committed to remaining independent and community-owned. Our code is open source, and we value contributor input.

**Q: Can I use Harbor at work?**  
A: Absolutely! Harbor is reliable and professional. It's suitable for development, research, general browsing, and professional work.

**Q: What about mobile?**  
A: Mobile support is not planned in the near term. We're focused on desktop browsers. If you're interested in mobile development, consider contributing!

# Начало работы с Harbor Browser

> [English Version](./GETTING_STARTED.md)

Добро пожаловать в Harbor Browser! Этот гайд поможет вам загрузить, установить и начать использовать Harbor.

## Системные требования

### Windows
- **ОС:** Windows 10 или позже
- **ОЗУ:** 4GB минимум (8GB рекомендуется)
- **Дисковое пространство:** 500MB
- **Архитектура:** x86-64 или ARM64

### macOS
- **ОС:** macOS 10.15 или позже
- **ОЗУ:** 4GB минимум (8GB рекомендуется)
- **Дисковое пространство:** 500MB
- **Архитектура:** Intel или Apple Silicon

### Linux
- **Дистрибьютивы:** Ubuntu 20.04+, Fedora 33+ или похожие
- **ОЗУ:** 4GB минимум (8GB рекомендуется)
- **Дисковое пространство:** 500MB
- **Архитектура:** x86-64 или AArch64

## Установка

### Windows

#### Вариант 1: Инсталлятор
1. Загрузите `harbor-windows.exe` с [GitHub Releases](https://github.com/Ivantech123/Harbor/releases)
2. Дважды щёлкните инсталлятор
3. Следуйте мастеру установки
4. Запустите Harbor из меню Пуск или с рабочего стола

#### Вариант 2: Портативная версия
1. Загрузите `harbor-windows-portable.zip`
2. Распакуйте в нужное место
3. Запустите `harbor.exe`

#### Вариант 3: Microsoft Store (если доступно)
1. Поиск "Harbor Browser" в Microsoft Store
2. Нажмите Установить
3. Запустите из меню Пуск

### macOS

#### Вариант 1: DMG Инсталлятор
1. Загрузите `harbor-macos.dmg` с [GitHub Releases](https://github.com/Ivantech123/Harbor/releases)
2. Дважды щёлкните для монтирования образа
3. Перетащите Harbor.app в папку Applications
4. Запустите из Applications

#### Вариант 2: Командная строка
```bash
# Использование Homebrew (если доступно)
brew install harbor
```

### Linux

#### Вариант 1: AppImage
```bash
# Загрузка
wget https://github.com/Ivantech123/Harbor/releases/download/latest/harbor-linux.AppImage

# Сделать исполняемым
chmod +x harbor-linux.AppImage

# Запуск
./harbor-linux.AppImage
```

#### Вариант 2: Менеджер пакетов
```bash
# Ubuntu/Debian
sudo apt install harbor-browser

# Fedora
sudo dnf install harbor-browser

# Arch
yay -S harbor-browser
```

#### Вариант 3: Flatpak
```bash
flatpak install harbor-browser
flatpak run harbor-browser
```

## Первый запуск

1. **Загрузите и установите** следуя шагам выше
2. **Запустите Harbor** из приложений
3. **Установите как браузер по умолчанию** (рекомендуется)
   - Параметры → Браузер по умолчанию
   - Нажмите "Установить по умолчанию"
4. **Войдите** (опционально) для синхронизации
5. **Изучите функции** - Смотрите гайд по функциям

### Основные функции

- **Пространства** - Организуйте вкладки в отдельные рабочие области
- **Вкладки** - Расширенное управление вкладками с группами и закреплением
- **Разделённое представление** - Просмотр двух страниц одновременно
- **Закладки** - Организуйте избранное в папках
- **История** - Отслеживайте посещённые страницы
- **Параметры** - Настройте Harbor под себя

### Горячие клавиши

| Действие | Сочетание |
|----------|-----------|
| Новая вкладка | Ctrl+T (Windows/Linux), Cmd+T (Mac) |
| Новое окно | Ctrl+N (Windows/Linux), Cmd+N (Mac) |
| Закрыть вкладку | Ctrl+W (Windows/Linux), Cmd+W (Mac) |
| Вернуть вкладку | Ctrl+Shift+T (Windows/Linux), Cmd+Shift+T (Mac) |
| Увеличить масштаб | Ctrl++ (Windows/Linux), Cmd++ (Mac) |
| Уменьшить масштаб | Ctrl+- (Windows/Linux), Cmd+- (Mac) |
| На весь экран | F11 (Windows/Linux), Cmd+Ctrl+F (Mac) |
| Инструменты разработчика | F12 (Windows/Linux), Cmd+Option+I (Mac) |

## Настройка параметров

1. Нажмите **Меню** (☰) в верхнем правом углу
2. Выберите **Параметры**
3. Изучите категории:
   - **Основные** - Базовые опции
   - **Главная** - Настройки главной страницы
   - **Поиск** - Поисковая система
   - **Приватность и безопасность** - Параметры приватности
   - **Внешний вид** - Тема и цвета
   - **Моды** - Настройка UI с CSS

## Обновление Harbor

### Автоматические обновления
Harbor проверяет обновления автоматически. Когда доступно:
1. Нажмите на уведомление об обновлении
2. Загрузите и установите
3. Перезапустите Harbor

### Ручная проверка
1. Нажмите **Меню** (☰)
2. Выберите **О Harbor**
3. Проверьте наличие обновлений

### Канал Twilight
Чтобы использовать тестовый канал:
1. Перейдите в Параметры
2. Раздел "О программе"
3. Переключитесь на канал "Twilight"
4. Перезапустите Harbor

## Удаление

### Windows
1. Параметры → Приложения → Приложения и возможности
2. Найдите "Harbor Browser"
3. Нажмите → Удалить
4. Подтвердите удаление

### macOS
1. Откройте Finder
2. Перейдите в Applications
3. Найдите Harbor.app
4. Перетащите в Корзину

### Linux
```bash
# Ubuntu/Debian
sudo apt remove harbor-browser

# Fedora
sudo dnf remove harbor-browser

# Arch
yay -R harbor-browser
```

## Локальная настройка разработки

Хотите собрать Harbor из исходников? Смотрите [Гайд контрибьютинга](./CONTRIBUTING_RU.md#локальная-настройка-разработки).

### Быстрый старт
```bash
# Клонировать репозиторий
git clone https://github.com/Ivantech123/Harbor.git
cd Harbor

# Установить зависимости
npm install

# Подготовить среду
npm run init

# Запустить версию для разработки
npm start
```

## Решение проблем

### Harbor не запускается
- Попробуйте очистить кэш: Удалите папку профиля
- Переустановите Harbor
- Проверьте системные требования

### Падение при запуске
- Обновитесь до последней версии
- Проверьте ресурсы системы (ОЗУ, место на диске)
- Попробуйте безопасный режим (если доступен)

### Низкая производительность
- Проверьте Параметры → Производительность
- Отключите неиспользуемые расширения
- Очистите данные браузера

⚓ Запускаем Harbor — открытая бета

Harbor — браузер на движке Firefox с вертикальными вкладками и своим подходом к рабочему пространству. Выкладываем публичную бету.

Что внутри:
• Пространства — отдельные наборы вкладок для работы, учёбы и личного
• Важное — любимые сайты всегда под рукой, в один клик
• Разделение экрана — до четырёх вкладок рядом
• Быстрый просмотр — открыть ссылку поверх страницы, не уходя с неё
• Компактный режим — панели прячутся, пока не нужны
• Встроенный магазин модов для внешнего вида

Сделано с оглядкой на Россию:
• российские сайты открываются напрямую, даже когда включён VPN
• сертификаты Минцифры уже установлены
• интерфейс полностью на русском

Без телеметрии, со строгой защитой от отслеживания из коробки. Обновления приходят сами.

⬇️ Скачать (Windows 10/11, 64-бит):
https://github.com/Ivantech123/Harbor/releases/latest

Это бета: что-то может работать не так. Установщик пока без цифровой подписи, поэтому Windows покажет предупреждение — нажмите «Подробнее» → «Выполнить в любом случае».

## О Harbor

**Harbor Browser** - это независимый, открытый браузер на основе Firefox с инновационными функциями пользовательского интерфейса и широкими возможностями настройки.

### Главные преимущества

- 🎯 **Независимый** - Полностью отдельный от других проектов браузеров
- 🔒 **Безопасный** - Построен на проверенной основе безопасности Firefox
- 🎨 **Настраиваемый** - CSS-система тем с модами
- 🚀 **Быстрый** - Оптимизирован для современного веба
- 🌍 **Кроссплатформенный** - Windows, macOS и Linux
- 🗣️ **Многоязычный** - Поддержка 30+ языков
- 👥 **Открытый исходный код** - MPL-2.0, управляется сообществом

### Что делает Harbor уникальным?

Harbor представляет несколько инновационных функций:

- **Пространства** - Организуйте вкладки в изолированные рабочие области
- **Разделённое представление** - Просмотрите две страницы одновременно
- **Живые папки** - Динамические папки из GitHub/RSS
- **Расширенные вкладки** - Группы, закрепление, вертикальная боковая панель
- **Система модов** - Настройте UI с CSS
- **Сессии** - Автоматически сохраняйте и восстанавливайте сессии

## Быстрый старт

### Загрузка и установка

**Windows:**
```bash
# Загрузите с GitHub Releases
https://github.com/Ivantech123/Harbor/releases

# Запустите инсталлятор
harbor-windows.exe

# Или используйте портативную версию
harbor-windows-portable.zip
```

**macOS:**
```bash
# Загрузите DMG
harbor-macos.dmg

# Или через Homebrew
brew install harbor
```

**Linux:**
```bash
# Загрузите AppImage
wget https://github.com/Ivantech123/Harbor/releases/download/latest/harbor-linux.AppImage
chmod +x harbor-linux.AppImage
./harbor-linux.AppImage

# Или через менеджер пакетов
sudo apt install harbor-browser  # Ubuntu/Debian
sudo dnf install harbor-browser  # Fedora
```

### Первые шаги

1. **Запустите Harbor** из приложений
2. **Установите браузером по умолчанию** (опционально, но рекомендуется)
3. **Изучите функции** в Параметрах
4. **Настройте** внешний вид и поведение
5. **Установите расширения** из магазина Firefox

## Функции

### Основные функции

#### 🎯 Пространства
Организуйте просмотр в изолированные рабочие области:
- Каждое пространство имеет независимые вкладки
- Отдельные закладки и история
- Быстрое переключение между пространствами
- Идеально для проектно-ориентированного рабочего процесса

#### 📄 Разделённое представление
Просмотрите несколько страниц одновременно:
- Сравнение рядом
- Перетаскивание между представлениями
- Синхронная прокрутка (опционально)
- Отлично для исследования и многозадачности

#### 📑 Расширенное управление вкладками
Сложная организация вкладок:
- **Группы вкладок** - Группируйте связанные вкладки
- **Закреплённые вкладки** - Держите важные вкладки видимыми
- **Вертикальная боковая панель** - Компактный дисплей вкладок
- **Быстрый поиск** - Найдите вкладки мгновенно
- **Автосохранение** - Сессии сохраняются автоматически

#### 📁 Живые папки
Динамические папки, которые обновляются автоматически:
- **Интеграция GitHub** - Мониторьте репозитории
- **RSS-каналы** - Подпишитесь на контент
- **Умные закладки** - Автоматически организованные закладки
- **Пользовательские скрипты** - Создайте свои живые папки

#### 🎨 Настройка
Обширная настройка UI:
- **Система модов** - CSS-темы
- **Поддержка тем** - Светлая, тёмная и пользовательская
- **Цветовые схемы** - Сотни опций цветов
- **Контроль шрифтов** - Выберите шрифты и размеры
- **Опции макета** - Настройте панель инструментов и UI

### Дополнительные функции

- 🔐 **Режим приватности** - Просмотр без истории
- 🔖 **Закладки** - Организуйте и синхронизируйте

## Установка

### Установка на Windows

#### Способ 1: Инсталлятор (рекомендуется)
1. Загрузите `harbor-windows.exe` с [Releases](https://github.com/Ivantech123/Harbor/releases)
2. Дважды щёлкните инсталлятор
3. Следуйте мастеру установки
4. Выберите место установки
5. Выберите ярлыки в меню Пуск
6. Нажмите Установить
7. Запустите Harbor

#### Способ 2: Портативная версия
1. Загрузите `harbor-windows-portable.zip`
2. Распакуйте в нужное место
3. Установка не требуется
4. Запустите `harbor.exe` напрямую

#### Способ 3: Microsoft Store
1. Поиск "Harbor Browser" в Microsoft Store
2. Нажмите Установить
3. Дождитесь загрузки и установки
4. Запустите из меню Пуск

### Установка на macOS

#### Способ 1: DMG Инсталлятор
1. Загрузите `harbor-macos.dmg` с [Releases](https://github.com/Ivantech123/Harbor/releases)
2. Дважды щёлкните `harbor-macos.dmg`
3. Перетащите Harbor.app в папку Applications
4. Извлеките дисковый образ
5. Откройте папку Applications
6. Дважды щёлкните Harbor.app

#### Способ 2: Homebrew
```bash
brew tap Ivantech123/harbor
brew install harbor
```

#### Способ 3: Командная строка
```bash
cd /Applications
open Harbor.app
```

### Установка на Linux

#### Способ 1: AppImage
```bash
# Загрузка
wget https://github.com/Ivantech123/Harbor/releases/latest/download/harbor-linux.AppImage

# Сделать исполняемым
chmod +x harbor-linux.AppImage

# Запуск
./harbor-linux.AppImage

# Опционально: Переместить в bin
sudo mv harbor-linux.AppImage /usr/local/bin/harbor
```

#### Способ 2: Менеджер пакетов

**Ubuntu/Debian:**
```bash
sudo add-apt-repository ppa:ivantech123/harbor
sudo apt update
sudo apt install harbor-browser
```

**Fedora:**
```bash
sudo dnf copr enable ivantech123/harbor
sudo dnf install harbor-browser
```

**Arch:**
```bash
yay -S harbor-browser
```

#### Способ 3: Flatpak
```bash
flatpak install flathub app.ivantech123.Harbor
flatpak run app.ivantech123.Harbor
```

## Использование

### Базовая навигация

| Действие | Клавиша | Мышь |
|----------|---------|------|
| Новая вкладка | Ctrl+T | Меню → Новая вкладка |
| Новое окно | Ctrl+N | Меню → Новое окно |
| Закрыть вкладку | Ctrl+W | Средняя кнопка мыши |
| Вернуть вкладку | Ctrl+Shift+T | Правый клик на X |
| Назад | Alt+← | Кнопка назад |
| Вперёд | Alt+→ | Кнопка вперёд |
| Обновить | Ctrl+R | Кнопка обновить |
| Остановить | Esc | Кнопка остановить |

### Пространства

**Создание пространств:**
1. Щёлкните кнопку "+" в боковой панели Пространств
2. Назовите ваше пространство
3. Настройте внешний вид
4. Начните добавлять вкладки

**Переключение пространств:**
- Щёлкните название пространства в боковой панели
- Используйте горячую клавишу (настраиваемая)
- Жест прокрутки (trackpad macOS)

### Разделённое представление

**Включение разделённого представления:**
1. Щёлкните кнопку Разделённое представление в панели инструментов
2. Выберите вкладки для каждой стороны
3. Просмотрите независимо
4. Перетащите между сторонами для изменения размера

**Выход из разделённого представления:**
- Щёлкните "X" на панели Разделённого представления
- Щёлкните кнопку полноширинного представления в панели инструментов

### Моды и настройка

**Установка модов:**
1. Параметры → Моды
2. Просмотрите доступные моды
3. Щёлкните "Установить"
4. Перезапустите браузер

**Создание пользовательских модов:**
1. Параметры → Моды
2. Щёлкните "Создать мод"
3. Отредактируйте CSS
4. Примените и предпросмотрите
5. Сохраните мод

## Разработка

### Сборка из исходников

**Требования:**
- Node.js 18+
- Python 3.10+
- Rust (последняя стабильная версия)
- Git
- Платформенный SDK (специфичный для Windows/macOS/Linux)

**Настройка:**
```bash
# Клонирование репозитория
git clone https://github.com/Ivantech123/Harbor.git
cd Harbor

# Установка зависимостей
npm install

# Подготовка среды
npm run init

# Запуск версии разработки
npm start
```

**Сборка:**
```bash
# Сборка для всех платформ
npm run build

# Сборка только UI
npm run build:ui

# Пакетирование для распределения
npm run package
```

### Команды разработки

```bash
npm start          # Запуск версии разработки
npm run build      # Сборка для всех платформ
npm run lint       # Проверка стиля кода
npm run lint:fix   # Исправление проблем стиля
npm test           # Запуск тестов
npm run test:dbg   # Отладка тестов
```
